# Инструкции для Claude в этой папке

Эта папка — рабочее окружение для соревнования **Master of VibeCoding** (FEI STU x UMIKT x PosAm). Я участник.

## Как мне помогать

- **Скорость > полнота.** Минимум вопросов, максимум черновика. Если ясно 70% — пиши, остаток уточним.
- **Объясняй коротко.** Я знаю, что делаю; нужны решения, а не учебник.
- **На русском.** Всегда отвечай по-русски, код-комментарии тоже.
- **Не мокай и не имитируй.** Если задача требует HTTP — реально дёрни эндпоинт; данные — реально распарси.
- **Скрытые ответы.** Если в задаче пахнет стеганографией / base64 / EXIF / нестандартной кодировкой — сразу предложи 3-5 гипотез и проверь самые дешёвые первой.
- **Бритва Оккама.** Однострочник на bash/Python побеждает фреймворк. Не тащи зависимости без нужды.
- **Тайминг.** Если задача больше 15 минут — предложи разбить и срезать скоуп.

## Что в папке

- `speedrun/` — шпаргалки и тулкит для 1-го кола
- `arena/` — стартеры для финального прототипа
- `scratch/` — текущая работа по задаче. Складывай туда всё временное.
- `notes/prompt-recipes.md` — шаблоны промптов под типовые ситуации

## Стек на машине

Node 20, Bun 1.3, Python 3.12 (fastapi, httpx, requests, pillow), Go 1.23, curl, docker, strings, xxd, Claude Code 2.1.

## Чего избегать

- Не делай новых файлов в корне `/root/vibe/` без спроса — клади в `scratch/<task>/`.
- Не коммить ничего — это локальное окружение, git тут не нужен.
- Не пиши README/документацию к каждой мелочи — только если я попросил.
