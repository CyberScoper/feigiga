# Промпт-рецепты для Claude

Шаблоны под типовые ситуации соревнования. Подставь `<...>` и кидай как есть.

---

## 1. Speed Run: "найди баг"

```
В файле <path> есть баг: <симптом>.
Задача: <условие задачи дословно>.

Сначала прочитай файл целиком, потом сформулируй ОДНУ гипотезу о причине.
Не правь код, пока я не подтвержу гипотезу.
```

---

## 2. Speed Run: "дёрни API и обработай"

```
Эндпоинт: <URL>
Авторизация: <headers / token / нет>
Что нужно получить: <описание целевого ответа>

Напиши минимальный python (httpx) скрипт.
Никакого retry/обработки ошибок — happy-path, я отлажу руками если упадёт.
Сохрани в scratch/<task>/solve.py и запусти.
```

---

## 3. Speed Run: "тут скрытый ответ"

```
У меня файл <path>. Подозреваю, что в нём спрятан ответ.

Сначала запусти /root/vibe/speedrun/hidden.sh <path> и покажи вывод.
По выводу дай 3 гипотезы (base64? EXIF? байты после конца картинки? ...).
Я выберу одну — её и докручиваем.
```

---

## 4. Speed Run: "распарси эти данные"

```
Файл: <path>, формат: <CSV/JSON/XML/что-то странное>.
Нужно достать: <поля / агрегат / фильтр>.

Прочти первые 20 строк, покажи мне структуру, потом пиши парсер.
Используй stdlib (csv/json), без bs4/pandas, если не критично.
```

---

## 5. Arena: "сделай прототип к задаче"

```
Задача: <дословно>.

Я думаю взять <starter-web|starter-api|starter-cli>.
Скопируй стартер в scratch/arena/, переименуй демо-эндпоинт под задачу,
запусти и покажи мне URL.

Один happy-path. Без auth, без БД, без обработки edge cases.
Если что-то требует выбора — выбери сам в сторону "проще".
```

---

## 6. Arena: "питч через 5 минут"

```
Я финалист, через <N> минут — питч на 60 сек.
Контекст задачи: <1-2 фразы>.
Что я сделал: <1-2 фразы>.

Сгенерируй текст по шаблону /root/vibe/pitch.md.
Простые слова, без воды. Без слова "leverage".
Закончи одной фразой про "что дальше за неделю".
```

---

## 7. Универсальный "застрял"

```
Я сижу 10+ минут над <конкретная подзадача>.
Что я уже попробовал: <список>.

Не предлагай решение. Сначала задай мне ОДИН уточняющий вопрос,
который мог бы изменить подход.
```

---

## 8. Когда AI начал "галлюцинировать"

```
Stop. Перечитай <файл/доку/мою задачу> ещё раз.
Не предлагай решений, пока не процитируешь дословно строку, на которую опираешься.
```

---

## Антипаттерны промптов

- "Напиши полное приложение для X" — Claude насочиняет фичи, которых нет в задаче.
- "Сделай красиво" — субъективно, тратит токены. Говори "минимально стильно, тёмная тема".
- "На всякий случай добавь try/except" — добавит везде, читать невозможно. Скажи "без обработки ошибок".
