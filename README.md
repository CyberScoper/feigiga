# Master of VibeCoding — рабочее окружение

Тут всё, что должно быть под рукой во время соревнования.
AI разрешён как co-pilot. Побеждает понимание задачи + быстрый рабочий прототип.

## Структура

- `speedrun/` — арсенал для 1-го кола (debug, API, данные, скрытые ответы)
- `arena/` — стартеры для финала (web-демо, API, CLI) + шаблон pitch'а
- `notes/` — промпт-рецепты, заметки, идеи
- `scratch/` — мусорка для одноразового кода во время соревнования
- `checklist.md` — пре-флайт перед выходом из дома
- `pitch.md` — каркас финального питча на 60 сек
- `CLAUDE.md` — инструкции Claude'у, когда он работает в этой папке

## Правила игры

1. **Сначала прочитай задачу вслух**, выпиши вход/выход/ограничения — потом трогай AI.
2. **AI = младший напарник**: пусть генерит варианты, но факты ты проверяешь руками.
3. **Прототип > красота**: работающее уродство бьёт красивый замысел.
4. **Засеки время на пункт**: если буксуешь >10 минут — меняй угол атаки.
5. **Сохраняй артефакты** в `scratch/<task-name>/`, не теряй контекст между задачами.

## Быстрый старт во время соревнования

```bash
cd /root/vibe
# для Speed Run задачи
mkdir -p scratch/task-N && cd scratch/task-N
# скопируй нужный шаблон из speedrun/ или arena/
```
