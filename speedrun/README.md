# Speed Run — стратегия и арсенал

Короткие задачи под таймер. По описанию формата:
**debugging, работа с API, работа с данными, поиск скрытых ответов.**
Топ-6 проходит в финал.

## Стратегия

1. **Сначала прочти всё условие до конца.** В формате обещаны "скрытые чытаки" — первое впечатление часто обманывает.
2. **Выпиши вход/выход/ограничения** в `scratch/task-N/spec.md`. Это быстрый ритуал, который ловит подвохи.
3. **Прежде чем писать код — спроси: где может быть подвох?**
   - Нестандартная кодировка / encoding?
   - "Очевидный" ответ слишком очевиден?
   - В ответе API есть пагинация / rate-limit / headers?
   - Данные содержат мусор / дубли / NaN?
4. **AI = генератор гипотез, не оракул.** Спроси у него 3-5 вариантов, дёрни самый дешёвый, проверь.
5. **Засекай 10 минут на пункт.** Если буксуешь — выходи на меняй угол.

## Файлы

- `api.sh` — curl-приёмы и заготовки для HTTP
- `debug.md` — алгоритм отладки + типовые баги
- `hidden.sh` — детектор скрытых ответов (base64/hex/EXIF/strings/...)
- `data.py` — заготовка для парсинга JSON/CSV/XML/HTML
- `scratch.py` / `scratch.ts` — пустые песочницы
