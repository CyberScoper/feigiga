# Vibe Arena — финал

Одна неизвестная задача, 60-90 минут, потом 60-сек питч + Q&A.

## Стратегия первых 10 минут

1. **5 мин — чтение и каркас замысла.** Запиши в `notes/arena-task.md`:
   - кто пользователь
   - что он хочет сделать в одно действие
   - что считается "работает"
2. **2 мин — выбор стека.** Не думай долго:
   - Нужен UI / визуальный wow → `starter-web/` (Bun + один HTML)
   - Нужен backend / обработка → `starter-api/` (FastAPI)
   - CLI / скрипт-демо → `starter-cli/`
3. **3 мин — копия стартера в `scratch/arena/` и первый запуск.**
   ```bash
   cp -r arena/starter-web scratch/arena && cd scratch/arena
   ```

## Стратегия следующих 50 минут

- **Один happy-path до конца.** Не делай "ещё одну фичу", пока главная не работает целиком.
- **Не рисуй красоту до 40-й минуты.** Сначала логика, потом CSS.
- **Не борись с зависимостями.** Если что-то не ставится — выкини и сделай руками.
- **Сохраняйся каждые 15 минут** (`cp -r scratch/arena scratch/arena.backup`).

## Последние 10 минут

- Прорепетируй питч (`/root/vibe/pitch.md`)
- Проверь, что демо запускается **одной командой** из чистого терминала
- Закрой посторонние вкладки — на проекторе видно всё

## Стартеры

- `starter-web/` — статика, открывается прямо в браузере. Идеально для "сделай интерфейс к API".
- `starter-api/` — FastAPI на 8000. CORS открыт, hot-reload.
- `starter-cli/` — Python CLI на argparse. Когда задача — обработка файла или данных.
