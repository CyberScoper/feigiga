# starter-web — мгновенный фронтовый прототип

Один HTML без сборки и npm. Открывается в браузере, всё работает.

## Запуск

```bash
./serve.sh
# → http://localhost:3000
```

Или просто открой `index.html` двойным кликом — для чистого фронта хватит.

## Что менять под задачу

- `<h1>` — название демо
- блок `input/button/out` — UI
- функция `run(input)` — твоя логика
- если нужен бэкенд — раскомментируй `fetch("http://localhost:8000/...")` и подними `starter-api/`

## Когда выбирать этот стартер

- Нужно показать визуально работающий интерфейс
- Задача про "сделай простой UI к ..."
- Жюри будет тыкать пальцем в экран
